# MoneyManager - スプレッドシート連携家計簿Webアプリ (ライトモード & 4シート版)

Googleスプレッドシートの4つのシート（週次資産記録、支出記録、収入記録、サブスク管理）をデータベースとして活用し、ローカルのブラウザから美しくデータを視覚化・追記できる、自分専用の家計簿アプリケーションです。

清潔感がありコントラストが高く、使いやすい「ライトクリーン」デザインを採用しています。ビルド不要のHTML/CSS/JSで構成されているため、ファイルをブラウザで開くだけで即座に起動できます。

---

## 特徴と連携機能

1. **清潔感のあるライトモード**: 白と高コントラストのインディゴを基調とした、モダンで直感的なデザイン。
2. **4つのスプレッドシート完全対応**:
   - **週次資産記録 (閲覧専用)**: 週次の総資産トレンドと、ポートフォリオ内訳（預金、株式、投信、ポイントなど）をインタラクティブな折れ線グラフで表示。
   - **支出記録 (閲覧・追加)**: 月別の変動費を集計し、カテゴリ別支出割合（ドーナツ）と推移を表示。
   - **収入記録 (閲覧・追加)**: 額面、税金、社会保険料、手取りなどの詳細な給与明細情報を管理。
   - **サブスク管理 (閲覧専用)**: 年払いや月払いのサブスク金額を「月額換算」し、今月の固定支出として自動合算。
3. **収入詳細フォームと給与計算**:
   - フォーム入力時に自動で「控除合計」および「手取り」をリアルタイム計算。
   - 社会保険料の計算を支援する「簡易内訳電卓モーダル」を搭載。健康保険、厚生年金、雇用保険、介護保険を個別に入力して合計額を自動反映。
   - 「その他控除」はデフォルトで `2,260円` が自動セットされます（手動で調整可能）。
4. **表記揺れの自動修正**: `2026年01月`, `2026-02`, `2026/1` などの混在した年月表記をスマートにパースして月次集計。

---

## シート構成（スプレッドシート側）

連携するスプレッドシートには、以下のシートとヘッダー列が必要です。
*(※新規の空のスプレッドシートに連携した場合、GASが自動的に以下のシートとサンプルデータを作成します)*

1.  **週次資産記録**
    *   ヘッダー列: `日付` | `総資産` | `預金・現金・暗号資産` | `株式(現物)` | `投資信託` | `ポイント`
2.  **収入記録**
    *   ヘッダー列: `年月` | `収入区分` | `総支給額` | `所得税` | `住民税` | `社会保険料` | `その他控除` | `控除合計` | `交通費` | `手取り`
3.  **支出記録**
    *   ヘッダー列: `年月` | `日付` | `項目` | `金額` | `備考`
4.  **サブスク管理**
    *   ヘッダー列: `年` | `媒体名` | `支出金額` | `支払回数 / 年` | `年間支払額` | `月当たり支払額`

## セットアップ手順

### ステップ 1: スプレッドシートと GAS (API) の設定

1. ご自身のGoogleスプレッドシートを開きます。
2. 上部メニューから **「拡張機能」 > 「Apps Script」** を選択します。
3. すべての初期コードを消去し、プロジェクト内の `gas_api.js` の中身をすべてコピー＆ペーストして保存します（フロッピーアイコンまたは `Ctrl + S` / `Cmd + S`）。
4. 画面右上の **「デプロイ」 > 「新しいデプロイ」** をクリックします。
5. 左側の「歯車マーク」から **「ウェブアプリ」** を選択し、以下のように設定します：
   - **次のユーザーとして実行**: `自分 (YOUR_EMAIL@gmail.com)`
   - **アクセスできるユーザー**: `全員`
6. デプロイをクリックし、初回のみポップアップされる「アクセスの承認」を行います。
   - 使用するアカウントを選択し、詳細リンクから「MoneyManager (安全ではないページ) に移動」をクリックして、権限の「許可」をクリックします。
7. 生成された **「ウェブアプリのURL」** をコピーします。

---

### ステップ 2: Webアプリの起動

ターミナルで本フォルダに移動し、以下のコマンドを実行します：

```bash
python3 -m http.server 8000
```

起動後、ブラウザで [http://localhost:8000](http://localhost:8000) にアクセスします。
*(最初はデモモードとして、ご提供いただいた画像に基づいたリッチな家計簿データがロードされます)*

---

### ステップ 3: 連携の設定

1. 起動したWebアプリのメニューから **「設定」** を開きます。
2. 「Googleスプレッドシート連携」項目にコピーした **「GAS Web App URL」** を貼り付けます。
3. **「接続を保存してテスト」** ボタンをクリックします。
4. 接続に成功すると、左下のステータスが **「スプレッドシート同期中（緑色）」** に変わり、スプレッドシートの実際のデータと同期します。

---

### ステップ 4: GitHub PagesでのWebサイト公開手順

本アプリはHTML、CSS、JSのみの静的サイトであるため、GitHub Pagesを使って無料でインターネット上に自分専用のWebサイトとして公開し、スマートフォンからアクセスすることができます。

1. **GitHubでリポジトリを作成**
   - GitHubにログインし、新しいリポジトリ（例: `money-manager`）を**パブリック（Public）**で作成します。
2. **ローカルからコードをプッシュ**
   - ターミナルを開き、本フォルダ（`kakeibo-app`）に移動して以下のコマンドを実行します：
     ```bash
     # gitの初期化
     git init
     git add .
     git commit -m "Initial commit"
     git branch -M main
     
     # リモートリポジトリの紐付け (YOUR_USERNAMEを自身のユーザー名に置き換えてください)
     git remote add origin https://github.com/YOUR_USERNAME/money-manager.git
     
     # プッシュ
     git push -u origin main
     ```
3. **GitHub Pagesの設定を有効化**
   - GitHub上の作成したリポジトリページを開き、右上メニューの **「Settings」** (設定) を開きます。
   - 左側サイドバーから **「Pages」** を選択します。
   - **Build and deployment** の設定で、Sourceが「Deploy from a branch」になっていることを確認し、**Branch** で `main` および `/ (root)` を選択して **「Save」** をクリックします。
4. **公開サイトへのアクセス**
   - 1〜2分待つと、画面上部に公開URLが表示されます。
     *(URL例: `https://YOUR_USERNAME.github.io/money-manager/`)*
   - このURLにスマートフォンのブラウザからアクセスすることで、いつでも家計簿を確認・入力することができます。

> [!NOTE]
> **セキュリティと個人情報について**:
> 本アプリはサーバーを持たないサーバーレス設計です。設定画面に入力した「GASのURL」は、**アクセスしているご自身のブラウザの `localStorage`（ローカルストレージ）にのみ保存されます**。GitHub上のリポジトリや第三者にURLが送信されることは一切ありませんので、完全にプライベートで安全な状態が維持されます。
